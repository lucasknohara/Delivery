# GourmetOn

Landing Page do sistema GourmetOn.

## Sobre o projeto

O GourmetOn é uma landing page de um aplicativo de delivery de comida, o projeto apresenta as principais características do aplicativo e utiliza uma API de receitas para exibir opções de pratos.

## Tecnologias utilizadas

- React
- Vite
- Tailwind CSS
- JavaScript
- Fetch API
- JSON

## Funcionalidades

- Apresentação do aplicativo
- Benefícios do GourmetOn
- Funcionalidades do aplicativo
- Depoimentos
- Consulta de receitas por API
- Formulário de contato
